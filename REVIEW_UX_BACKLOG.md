# Review UX backlog (Phase 3+)

Items from the Review Site Checklist deferred after Waves 1–2 (dismissible UI + look & feel).

## Dynamic layouts

- Bento-style shelf home (featured review, currently watching, stats tiles)
- Switchable library views: poster grid, compact list, masonry, timeline
- Media-type adaptive grids (taller covers for manga/manhwa)
- Infinite scroll / virtualised grid for large libraries
- Persist view, sort, and filters per user

## Review page depth

- Category rating breakdown (story, art, music, characters, pacing)
- Pros / cons chips; “Who is it for”; mood tags beyond freeform tags
- Related titles (“if you liked this”)
- Previous / next review navigation
- Sticky compact header with rating + status on scroll
- Pull-quote layout for short verdicts vs reading layout for long essays

## Trust & distribution

- Open Graph / share unfurl images for WhatsApp, X, Discord
- Cover art and data-provider attribution lines
- Rewatch count and richer progress copy (“finished 24/24”)
- Server-side dominant-color pipeline (replace client canvas sample)

## Motion & a11y stretch goals

- View Transitions API between shelf and entry
- Prefer AVIF/WebP generation on upload
- Audit all interactive targets for 44px on every breakpoint
